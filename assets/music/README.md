# 牌桌小憩

为本项目编写的原创器乐背景音乐。92 BPM，D 大调，24 小节，约 62.61 秒，立体声 PCM WAV，可循环。

旋律、伴奏和编曲均在 `scripts/compose-music.cjs` 中明文记录；木琴、拨弦、气声音色、低音和沙锤全部通过数学振荡器及确定性噪声生成。没有使用第三方歌曲、录音、采样包或外部音源，也未要求模仿特定音乐人或作品。

运行 `node scripts/compose-music.cjs` 可重建相同音频。循环边界保留混响尾音。

该生成流程不附加第三方音乐素材许可要求。以上为素材来源记录，不代表对全球所有既有旋律作过相似性检索或作出绝对不侵权保证。
