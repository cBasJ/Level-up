# 拖拉机 · 四人双副升级

浏览器拖拉机游戏，同时保留单机练习与四人联网好友房。联网版使用 TypeScript、Fastify、WebSocket 与 SQLite，服务器负责所有发牌、判牌和结算。

## 四人好友房（当前迁移阶段）

使用 Node.js 24，首次运行：

```sh
npm install
npm start
```

打开 http://127.0.0.1:4173/ 进入游戏大厅，可以选择单机练习、创建好友房或输入六位房间号加入。四人均准备后开始。单机入口为 `/index.html`，联机入口为 `/online.html`，个人资料为 `/profile.html`。本机测试四位玩家时，请使用四个独立浏览器配置/隐私会话；同一浏览器身份的多个标签页只保留最近一次连接。

大厅与资料页沿用草地、深绿和暖金配色。个人资料支持昵称、四种头像和签名编辑并保存到数据库；战绩统计来自服务器已经结算的联网牌局，只展示本人参加的对局，不包含单机练习。

单机和联机共用 `table-layout.js` 的等比缩放、手牌叠放和出牌排布：手机竖屏旋转为横向牌桌，适配可视视口与安全区；手牌露出左侧点数，选牌仅抬高且保持叠放顺序；对家出牌与自己出牌沿同一中线，最大牌标记位于牌组侧边。未轮到自己时隐藏出牌/提示按钮，上轮和底牌固定在右下方独立区域，倒计时使用简洁数字。

抢主按钮在发牌快照刷新中保持同一个 DOM 节点，避免触摸按下到松开期间因重建按钮而丢失点击。花色数量只统计普通花色牌，是否可亮仍由实际级牌和当前反主档位判断。

点击「不叫」后，本局不能再抢主、反主或自保；已有亮主不撤销，下一局重新开放。联机由服务器校验并保存，刷新、重连或重启服务不会恢复本局叫主资格。单机同样锁定，发牌阶段仍会加速发牌。

牌面统一使用 `assets/cards/` 下的 54 张 PNG 正面图及一张牌背；普通牌另附 SVG 源文件。大小王为原创森林庆典插画，星标由规则动态叠加。单机、联机、手牌、桌面出牌和底牌保持统一 2:3 比例，不拉伸图片。`node scripts/build-deck.cjs` 可重新导出普通牌和牌背；大小王的来源与提示词在 `assets/cards/README.md`。

同一局域网的手机/电脑联机，在 PowerShell 使用：

```powershell
$env:HOST='0.0.0.0'
npm start
```

其他设备访问 `http://服务器的局域网IP:4173/online.html`，需网络和系统防火墙允许访问此端口。默认仅监听本机。`PORT` 可更改端口，`TRACTOR_DB` 可设置数据库文件位置。公网正式部署尚未配置。

- 服务器统一随机发牌，客户端仅收到自己的手牌与公共牌桌信息；首局抢主坐庄、后续轮庄、甩牌失败回退、扣底、A 级结束均复用已有规则。
- 四人对局、8 秒反主、30 秒埋底/出牌超时托管、仅剩一张时自动出牌。关闭页面后托管计时继续，不暂停其他玩家。
- 断线自动重连；同一浏览器刷新恢复身份和房间；重复请求编号不会重复出牌。新身份不能冒领原座位。
- SQLite 保存身份令牌的哈希、房间完整快照、操作类型记录、请求去重结果及每局结算。数据库在 `data/tractor.sqlite`，已忽略 Git；备份应使用 SQLite 在线备份或停止服务后复制数据库。清理浏览器本地存储会丢失本地访客登录凭证。
- 未开局可离开房间；进行中离线转超时托管；结算后可离开或全员准备继续。结算后有人离开则剩余房间重新从 2 开始。
- 保留男女录音切换、选牌、拖拉机标记、强制跟牌、公开信息甩牌/缺门提示、上轮回看（2 秒可手动返回）。联网中回看不会暂停服务器倒计时。测试发牌和任意改级不进入联网对局。

### 架构与后续边界

`engine.js` 是单机与服务端共用的纯规则引擎；`backend/game.ts` 是权威牌局状态机；`backend/server.ts` 提供身份接口、房间、WebSocket 和静态资源白名单；`backend/store.ts` 是数据库事务边界；`online.js` 是只接收个人视图的联网客户端。现有单机实现保留，继续作为规则和交互验证入口。

当前是单进程好友房开发版本，数据库采用本机可直接运行的 SQLite，不是 PostgreSQL/Prisma。房间操作在单个进程中同步串行执行，快照与去重结果同一事务提交；不可将多个进程同时运行并共享同一数据库作为扩容方式。服务重启后恢复快照并继续倒计时，不会一次跳过所有离线时间。

下一阶段：把存储层换为 PostgreSQL（包含迁移、异步事务与房间串行队列），补齐正式账号和微信登录、房间清理与账号恢复、HTTPS/WSS 部署、监控与备份；再将客户端移植到 Cocos Creator/微信小游戏。当前访客身份不能替代正式微信登录；未配置 AppID、域名、云服务器或发布小游戏包。Redis、多进程房间分配和匹配服务等待扩容时再引入。

画面采用横屏草地牌桌、卡通头像、金色主牌星标和立体按钮。底部手牌根据张数调整间距，埋底时 33 张也可完整显示。屏幕会等比缩放，竖屏时牌桌旋转为横屏方向；建议手机横持。右上角可打开规则、记录、新开一场或全屏。

底部的「底牌」按钮允许庄家在埋底后查看自己的底牌，其他玩家仅在结算后查看。出牌时中间徽章显示轮到谁操作；发牌后的反主区则显示真实的 8 秒倒计时。

顶部面板显示当前局数、轮次、已出几家、桌面分数和当前领先玩家。每次出牌后，最大的一组牌加金色描边和「当前最大」标记，四家出齐改为「本轮最大 · 胜」，下一轮清除。桌面分数是当前轮已打出分牌的合计，与左上角闲家累计抓分分别计算。

## 运行

直接用浏览器打开 `index.html`，或安装 Node.js 后运行：

```sh
npm start
```

打开 http://127.0.0.1:4173 。运行 `npm test` 检查规则和完整模拟对局。

## 操作

每局以 100 毫秒一张轮流发牌，正常发完约 10 秒。抢主按钮旁的数字表示手牌中对应花色的普通牌张数（不计级牌，普通主花色牌继续计数），随发牌实时更新；大小王各显示自身张数。是否能亮主仍按实际级牌或王的数量判断。手牌到手后即可点对应花色抢主，牌未到手时不可亮；亮牌不会消耗手牌。可点「加速发牌」，加速后仍保留反主窗口。四人各拿到 25 张后进入 8 秒反主倒计时，有效反主或自保重新计时；点「不反主，继续」将当前等待缩短至至多 3 秒，仍给电脑反主机会。双大王无主不再等待反主：发牌中亮出会在发完后直接定主，发完后亮出立即定主。查看规则、记录等弹窗时，发牌和反主计时暂停。

定主后庄家才拿 8 张底牌，再扣 8 张；按住鼠标或手指滑动可连续选牌；从已选牌开始滑动可批量取消，反向滑回缩小选择范围。默认点对子会选中两张，跟单张时仍选一张；可以切换底部「单张选择」或按住 Shift 拆对。选完点击出牌。提示按钮选择建议牌，不自动替你出牌。每局结束会在结算面板自动亮出全部 8 张底牌及底分，可继续升级。每次打开、刷新游戏或点击「新开一场」时，双方从 2 开始，首局由最终亮主或反主成功者坐庄（亮王无主同样适用），后续按结算轮庄；点击「再来一局」则保留本场级数，后续按结算轮庄。

底部「上轮」展示上一轮四家出牌 2 秒，期间暂停牌局，可点击“返回”提前恢复当前桌面。出牌按手牌显示顺序排列。仅剩一张手牌且轮到自己时自动出牌。

正主级牌和大小王显示两颗星，其他主牌一颗星；手中可组成拖拉机的对子显示「连对」。合法选牌严格大于桌上当前最大牌时，在出牌按钮下方显示「您选取的牌大于其他玩家」，不读取未出的暗牌。

## 本版本约定

- 两副牌、四人对家合作，80 分上台；支持单张、对子、任意长度连续对子，以及同门单张、对子和拖拉机混合甩牌。
- 首局最终亮主或反主成功者坐庄，后续按结算轮庄，反主只改变主花色；双王无主由亮王者坐庄。无人亮主时沿用预定庄家。
- 单张级牌 ＜ 同花色级牌对子 ＜ 双小王 ＜ 双大王；同档不可互反。可补同花色对子自保，当前亮主者不能换花色或用王反自己；被反掉后可以用更高档位反回。电脑仅使用已到手的牌抢主、反主或自保。
- 双小王、双大王均叫无主；无人亮主也默认无主。无主时只有级牌和王是主牌，大王 ＞ 小王 ＞ 四种同大的级牌；副牌按各自花色出牌、跟牌。同花色级牌对子与小王对子相邻，不同花色级牌不能混成对子。
- 只能在发牌和发完后的反主窗口亮牌，取底后不再反主。
- 有花色必须跟足；有拖拉机先跟拖拉机，不能完整匹配时先跟最长连续对子，再跟对子。完全缺门可用同型主牌毙牌。
- 单扣 ×2，对扣 ×4，n 连对扣底 ×2^(n+1)。0 分庄家升 3 级，5–35 升 2 级，40–75 升 1 级，80–115 闲家上台不升级，120 起每多 40 分升 1 级。
- 双方各自从 2 打到 A，之后循环至 2；不设必打级、跳级限制。
- 甩牌先拆出最长拖拉机，再拆对子和单张；其他三家（包括队友）没有同门更大的相应组合时成功。失败自动出被压制的最小组合（单张、对子、短拖拉机依次优先，同型按点数取小），不额外罚分。必须先跟同门并按甩牌中要求的组合尽量跟足拖拉机和对子，完全缺门时用全主且匹配全部组合才能毙牌。多家毙牌先比较最长拖拉机，再对子，再单张。甩牌扣底按首出最大组合计倍数。
- 不含炒底、联网多人和整局存档。电脑使用基础送分/抢分策略；仅根据自身手牌推断安全的甩牌，不读取其他玩家暗牌。

规则参考：[中山大学拖拉机比赛通知](https://bus.sysu.edu.cn/article/5784)、[中国农业大学双升比赛通知](https://sci.cau.edu.cn/art/2017/12/6/art_40525_758307.html)。甩牌参考：[JJ 升级](https://www.jj.cn/tractor/)。地方规则有差异，以游戏内说明为准。

`engine.js` 是无 DOM 的规则引擎，`app.js` 管理对局和 UI，`game.css` 为横屏牌桌布局。字体与图片均在本地，可离线游玩。`assets/` 中背景和头像由内置 imagegen 生成，完整提示词见 `assets/PROMPTS.md`。

浏览器验证：先 `npm install` 并 `npm start`，再运行 `node tests/browser.cjs` 和 `node tests/auction-browser.cjs`、`node tests/interaction-browser.cjs`。测试使用本机 Chrome 和 Playwright，覆盖逐张发牌、抢主反主链、无主完整对局、倒计时重置、无人亮主、自保、重开计时器清理、最大牌标记、分数面板、滑动选牌/触摸取消、对子连选、选牌大小提示、双星与拖拉机标记、甩牌跟牌/失败处理、上轮回看、最后一轮自动出牌、弹窗、手机横竖屏和手牌边界；截图保存到 `artifacts/`。`npm test` 还覆盖含无主在内的 100 局模拟及 80 局甩牌模拟。

测试阶段默认保证你的 25 张初始手牌含至少一组拖拉机和一张大王，仍使用完整的 108 张牌，不复制或增加牌。访问 `/?normal=1` 可恢复普通随机发牌。抓分首次达到或跨过 80 分时播放动画和提示音，120、180 分各播放提示音；扣底跨档也触发。音效在首次点击或键盘操作后启用。

手牌可随时预选（包括发牌、他人回合和上轮回看），其他玩家出牌不会清空你的预选；实际出牌仍须轮到自己。蓝色“甩”标记按自己的手牌与累计公开出牌推算，不读取他人手牌或暗底；同门蓝色标记牌可组成甩牌时显示，未标记不代表一定甩不了。玩家跟牌时出现异门牌即可确认缺首出门，头像旁显示缺门花色；主牌统一显示红色“主”。缺门记录每局重置。

右上角提供独立的“甩牌提示”和“缺门提示”开关，默认开启，设置保存在本机。关闭只隐藏标记，公开出牌和缺门记录仍持续更新，重新开启立即恢复。

最终定主牌缩小保留在亮主者头像左下角；发牌亮主区域突出展示当前亮主牌，移除单独的级牌大卡片。跟单张或对子时，新选择自动替换旧选择，取消选择直接再次点击手牌。根据跟牌规则必须出的牌自动选中，带“必”标记且不可取消。右上角“测试发牌”可随时切换，下一局生效并保存设置。

游戏设置面板集中管理测试发牌、甩牌提示和缺门提示。可选 2–A 作为我方起始级牌，点击“确定，重新开始”立即重新开场，对方从 2 开始。升级到 A 封顶，不跨越 A 循环；A 级牌局结算后整场结束，“再来一局”将双方重置到 2。结算页保留已公开底牌，移除重复查看按钮。普通花色按黑红交错分组，缺门后尽量保持交错，主牌内部大小和拖拉机相邻排列仍保留。

背景音乐《牌桌小憩》为本项目原创合成，约 63 秒无缝循环，不使用现成歌曲或采样包。首次点击游戏后播放；在游戏设置中可开关和调整音量，设置自动保存，切换到后台时暂停。音频位于 `assets/music/garden-cards.wav`，生成源码和完整乐谱位于 `scripts/compose-music.cjs`，来源说明见 `assets/music/README.md`。

游戏音效由振荡器合成，选牌为轻点音，出牌为落牌音。设置中“游戏音效”与“语音报牌”可独立开关并保存。中文报牌调用浏览器提供的中文语音：领出报点数、对子、甩牌张数；跟出报“跟牌”或“大你”；拖拉机始终报“拖拉机”。未提供中文语音的浏览器仍保留游戏音效。

报牌优先级更新：首家出主牌说“调主”（diào zhǔ）；用主牌首次毙过副牌说“毙了！”，以更大主牌再次压过说“盖毙！”，并增加强调音效。其余单张和对子始终报牌名，K 采用英文语音；其他拖拉机说“拖拉机”，其他多张跟牌按胜负说“大你！”或“跟牌”。强调报牌提高音高、速度与音量，具体音色取决于浏览器语音。

报牌细化：跟主牌时按是否压过当前最大牌说“大你”或“跟牌”（拖拉机仍说“拖拉机”）。首出甩牌优先于“调主”：对子加一张单牌的三张甩牌说“边三轮”，三张单牌说“甩牌”，四张及以上说“甩X张”，两张散牌说“甩牌”。主牌、副牌甩牌均遵守此命名。

最新报牌规则：甩两张说“甩牌”，甩三张及以上统一说“甩X张”，不再使用“边三轮”。任何拖拉机（包括首出主牌拖拉机、毙牌或盖毙的拖拉机）均优先说“拖拉机”。

三张甩牌按组成区分：一对加一张单牌报“边三轮”，三张单牌报“甩三张”，主牌、副牌均适用。两张仍报“甩牌”，四张及以上仍报“甩X张”，所有拖拉机报“拖拉机”。

录音报牌已接入：从用户提供的 `嚣张小姐_no-watermark.wav` 截取 50 条片段，存放于 `assets/voice/`，游戏优先播放原录音，包含 K/对K、亮反主、无主、调主、毙牌、边三轮等。音源仅录到“甩十张”，11–25 张使用系统中文语音补充。详细分段与来源记录见 `assets/voice/segments.json`、`assets/voice/README.md`，重建脚本为 `scripts/split-voice.py`。

设置面板新增音源切换按钮：女声“嚣张小姐”/男声“游戏主播”，即时生效并记住选择。两套各 50 条原录音，切换时清空旧语音队列，语音开启时自动试听“亮主”。
